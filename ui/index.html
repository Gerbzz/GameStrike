    GameStrike

    A local library for the HTML games you keep. Games run in their own player window with their own saves, offline unless you allow network access.

    Published by

    No account, no uploads. Imported games are not checked for safety; offline mode blocks their network requests but is not an operating-system sandbox. The look is an original homage to early-2000s console dashboards and uses no console maker's logos, fonts, or sounds.
